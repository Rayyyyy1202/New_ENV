## 一、方案概述

不使用 RPA / 浏览器抓取。系统核心能力:

1. **AI 解析用户输入表格**(报关单 / 装箱单:Excel / PDF / 图片),自动归一字段;
2. **AI 基于 Keepa 数据推荐可用的亚马逊对标链接**,并做**三重核验**(商标/材质/原产地)与**按要求择优**(品牌/原产地/材质开关 + 评论/评分门槛 + 最便宜/目标价);
3. **自建数据库 + 用户反馈沉淀长期知识库**:推荐的采纳 / 否决持续回流入库,系统积累专属对标知识库,**越用越准、越用越快**。

**核心流程**
用户上传表格 → AI 解析归一 → AI 电商翻译关键词 → Keepa 检索候选 → AI 相似度分析 → 三重核验 → 按要求择优 → **推荐可用亚马逊链接** → 用户反馈(采纳/否决)→ **入库沉淀长期知识库** → 反哺后续推荐。

**为什么用 Keepa**:合法商用 API、不碰反爬;自带价格历史 + 销量排名(BSR)+ 评论数据,推荐"可用"链接有据可依;稳定、可预算。

## 二、交付范围

### A. 核心功能(本次交付)

1. **AI 表格解析**:报关单 / 装箱单(Excel / PDF / 图片 OCR)解析与字段归一
2. **AI 对标推荐**:电商语境翻译 + 关键词生成 → Keepa API 检索候选 → AI 相似度分析 → 推荐可用亚马逊对标链接(含价格 / 销量 / 评论)
3. **三重核验**:品牌词 + EUIPO 商标库核验、材质比对、原产地判定
4. **自定义选品要求引擎**:品牌/原产地/材质开关 + 评论/评分门槛 + 最便宜 / 目标价择优(要求可保存为预设)
5. **数据库建设**:对标库 / 知识库 / 用户反馈 / 商品数据的统一存储与检索,作为长期数据资产
6. **长期知识库**:用户反馈(采纳 / 否决)闭环回流入库,沉淀专属对标知识库并反哺推荐,持续提升命中率
7. 部署上线 + 测试、培训与文档

### B. 可扩展(后续按需,另行报价)

> 架构预留扩展点,以下能力可随业务需要分期加上,核心系统不重构。

| 工单接入 | 飞书 / 企业微信 / 邮箱自动收单、读取聊天与附件 |
| 结果导出 / 回写 | CSV 导出、回写客户数据库 / ERP |
| 多站点扩展 | 亚马逊其他国家站点 |
